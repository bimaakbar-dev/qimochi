## Memulai Astro: Framework Web Modern

Astro adalah framework web modern yang dirancang untuk kecepatan. Dengan pendekatan **partial hydration**, Astro mampu mengirimkan HTML murni tanpa JavaScript di sisi klien kecuali jika benar-benar dibutuhkan.

## Instalasi

Untuk memulai, jalankan perintah berikut:

:::steps
- ### Buat proyek baru 
  ```bash
  npm create astro@latest
  ```

- ### Masuk ke direktori
  ```bash
  cd my-astro-project
  ```

- ### Install dependensi
  ```bash
  npm install
  ```

- ### Jalankan development server
  ```bash
  npm run dev
  ```
:::
